# Extra_Configuration_for_ArchLinux
This is a personal workflow which shows how i set up my own arch linux.

<br>

## Configuration
* [Arch Linux Configuration](Config.md)

<br>

## Features
* YAY and Pacman Package Manager Configs
* Flatpak Installation
* Reflector
* exFAT support
* CoolorControl
* Davinci Resolve Installation
* Virtual Machine Platform ( Qemu & KVM libvirt)
* Steam Installation & Uninstallation
* Excluding Files from being backed up by system snapshots
